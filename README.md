# 🚀 KODE — O Universo da Programação ao seu Alcance

> **Status do Projeto:** 🚀 Em desenvolvimento / Finalizado

O **KODE** é uma plataforma web criada para servir como um guia prático, visual e super direto para quem está iniciando no mundo da tecnologia. Nosso objetivo é centralizar tudo o que você precisa saber sobre o mercado de trabalho, as carreiras do momento e as tecnologias mais utilizadas, dando o empurrãozinho inicial que todo futuro desenvolvedor precisa.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias nativas para garantir leveza, semântica limpa e alta performance:

* **HTML5:** Estruturação organizada e semântica de todas as páginas.
* **CSS3:** Estilização moderna baseada em *Flexbox* e *Grid*, uso de variáveis, gradientes, efeitos de *glassmorphism* (blur) e animações interativas.
* **Google Fonts:** Integração das fontes *Inter*, *Roboto* e *Poppins* para uma tipografia moderna e legível.

---

## 🖥️ Telas do Projeto

O site conta com uma interface inspirada na estética *Cyberpunk / Dark Mode*, com navegação fluida e foco na experiência do usuário:

1.  **Página Inicial (`inicio.html`):** A nossa *Landing Page*. Possui um visual limpo, slogan de impacto, um botão dinâmico para iniciar a jornada e efeitos de iluminação em degradê para capturar a atenção de cara.
2.  **Sobre a Programação (`sobre.html`):** Explica de forma simples o conceito da programação, sua presença no cotidiano e os motivos para ingressar na área, organizados em cartões táteis interativos.
3.  **Linguagens Populares (`linguagens.html`):** Um catálogo interativo contendo as principais linguagens do mercado (HTML/CSS, JavaScript, Python, Java, C# e PHP) com animações de *hover* e *zoom* nos cards.
4.  **Áreas de Atuação (`areas.html`):** Apresenta os caminhos profissionais clássicos e emergentes: *Front-End*, *Back-End*, *Full-Stack*, *Inteligência Artificial* e *Cyber Security*.
